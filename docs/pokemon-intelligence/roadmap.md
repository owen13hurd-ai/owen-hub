# Pokemon Intelligence Roadmap

## Phase 1: Manual Truth

- Add product records.
- Add collection items.
- Add purchase records.
- Add price observations.
- Export records.
- Create Jarvis purchase decision notes.

Done when Owen can track a product from interest to purchase to collection.

## Phase 2: Better Analysis

- Add charts for collection value and purchase history. Started with Portfolio value breakdowns.
- Add release/watchlist workflow. Complete for Release Radar built from sets/products and watchlist coverage.
- Add duplicate warnings.
- Add duplicate merge action. Complete for collection rows that share name, condition, and location.
- Add stale price warnings.
- Add watchlist match scoring.
- Add Signals tab. Complete for buy-zone/watch/avoid/stale scoring against watchlist, manual prices, and restock observations.
- Add more fee presets.
- Add Collectr CSV import. Complete for preview and collection/card import.
- Add editable detail drawers. Complete for cards, products, collection items, watchlist items, restock observations, and price observations.

## Phase 3: Trusted Integrations

- Add Pokemon TCG API catalog import. Complete for set/card search and manual import.
- Add eBay active listing lookup if API access is configured.
- Expand Best Buy/Pokemon Center source documentation.
- Add Discord webhook alerts.

## Phase 4: Jarvis Intelligence

- Search Pokemon records from Jarvis. Complete for product lookup alongside Obsidian note search.
- Create draft Jarvis notes from the Jarvis dashboard. Complete for research, decisions, projects, sources, and tasks.
- Summarize purchase decisions. Started with one-click Pokemon Intelligence recap notes.
- Ask questions with citations.
- Add weekly Pokemon collecting recap.

## Maintainability

- Extract Pokemon Intelligence shared UI helpers. Complete for snapshot defaults, catalog types, editable field definitions, CSV export, product select, field labels, and edit-value cleanup.

## Catalog Pricing

- Add Pokemon TCG API card price snapshots. Complete for catalog cards that include TCGplayer market pricing.

## Phase 5: Advanced

- Barcode scanning.
- Image/photo storage.
- Route planning for local stores.
- Grading submission tracking.
- Marketplace opportunity scoring.
