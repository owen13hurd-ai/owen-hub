# Pokemon Source Policy

Pokemon Intelligence favors reliable, legal, and understandable data.

## Allowed Early Sources

- Owen's manual entries
- Official product pages
- Official retailer APIs where available
- Public API data with clear rate limits
- Saved email/newsletter information Owen has access to

## Delayed Sources

- Reddit, Discord, Bluesky, and X monitoring
- Marketplace listing imports
- Sold listing analysis
- Graded-card population data
- Automated retailer checks beyond permitted APIs

## Not Allowed

- Checkout bots
- CAPTCHA bypasses
- Queue bypasses
- Retailer account automation that violates terms
- Aggressive scraping
- Claims of real-time stock or market price without verified freshness

## Confidence Labels

- High: official source, direct receipt, or Owen-confirmed record
- Medium: reputable marketplace/API/source with clear timestamp
- Low: community signal, estimate, or unverified listing
